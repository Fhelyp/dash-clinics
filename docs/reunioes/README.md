# Reuniões do dash

Cada reunião que mudou regra ou escopo tem aqui um resumo com **contexto, decisões e próximos passos
com status**.

## Onde estão as transcrições

Este repositório é **público**. As transcrições na íntegra citam pacientes, comissões e conversas
internas, por isso **não são versionadas**:

- Cópia local, junto do repositório: `docs/_privado/reunioes/` (ignorada pelo git, ver `.gitignore`).
- Original: Brain, em `03-reunioes/AAAA-MM/`.

Se o repositório virar privado, dá para mover as transcrições para cá.

## Depois de uma reunião nova

1. Transcrição para o Brain e cópia em `docs/_privado/reunioes/`.
2. Resumo aqui (`AAAA-MM-DD-assunto.md`): contexto, decisões, pedidos, próximos passos com dono e status.
   Sem nome de paciente.
3. Pedido novo vai para o [BACKLOG](../contexto/BACKLOG.md); regra decidida, para o doc de decisões e a
   página de regras.
